# Whisper GUI
OpenAI Whisper transkript modeli için Tkinter tabanlı, ilk kurulum sonrası çevrimdışı çalışabilen basit arayüz.

# Gereklilikler
Bilgisayarınızın Nvidia GPU'ya sahip olması gerekmektedir.

# Kullanım
Arayüzün üst kısmından model ve dil seçimi yapılır. Script ilk defa çalıştırılıyorsa arayüzdeki "İlk Kullanım" kutucuğu işaretlenir. Sonrasında transkripti çıkarılacak medya dosyası ve çıktının kaydedileceği konum seçilerek "BAŞLAT" butonuna basılır. İlk kullanım kutucuğu seçildiği için gerekli kütüphaneler ve modeller otomatik olarak indirilip kurulacaktır ve işlem tamamlandığında eklenen dosyanın transkripti çıkarılarak belirtilen yola kaydedilecektir.
